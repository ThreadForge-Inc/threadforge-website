  2. Open the APK from your browser downloads or file manager. If prompted, allow your browser or file manager to Install unknown apps for this installation.

  • Key Rotation Notice: Development builds use a run-specific signing key. If you have an earlier development APK (such as 10.16.0 or 10.7.0) installed, export your records first, uninstall the previous app, and then install 10.16.1.
