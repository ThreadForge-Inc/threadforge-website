2. Installation & First Start

  1. Download ThreadForge-10.17.2-android.apk directly on your Android phone or transfer it from your PC.
  2. Open the APK from your browser downloads or file manager. If prompted, allow your browser or file manager to Install unknown apps for this installation.
  3. Because this development prerelease is signed with Threadforge Inc.'s own key rather than through Google Play, Google Play Protect may display an unrecognised developer prompt. Proceed only if the SHA-256 checksum matches above.
  4. Open ThreadForge. On first launch, the app unpacks the embedded Python 3.13 runtime and initializes your private SQLite workspace (roughly 20 seconds). You are signed in automatically; the owner token never leaves private application storage.

5. Updating, Security & Prerelease Notes

  • Permanent Signing Key: Since 10.16.2 the app is signed with Threadforge Inc.'s permanent key, in an approved build only, so 10.17.2 installs over 10.16.2 and 10.16.3 and keeps your records. Earlier APKs (10.16.1 and before) used one-off keys, so Android will not update them: back up or export your records, uninstall the previous app (this deletes its records on the phone), then install 10.17.2.
  • Back on Android 16: Back now returns to the previous page inside the app, and leaves the app only from the first page.
  • Loopback Isolation: The embedded backend binds exclusively to 127.0.0.1 on a random port each start. Android cloud backup (allowBackup=false) is disabled so owner tokens are never uploaded to third-party cloud backups.
