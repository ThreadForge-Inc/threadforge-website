Apple iOS & Mac OS · In development

Not released yet. Here is the real status.

ThreadForge does not have a downloadable iOS or Mac OS installer yet. The native SwiftUI client's source code exists in the repository and is reviewable today; nothing has been compiled on a Mac, signed, notarized, or submitted to Apple.

Why there is nothing to download

Three real gates, none of them cleared yet

No Apple Developer Program enrollment

Shipping on iOS or Mac OS requires a paid Apple Developer Program account ($99/year), D-U-N-S verification of Threadforge Inc., and a signed Paid Applications Agreement. None of this is in place yet.

No build has ever run on a real Mac

The source code has not been compiled on actual Apple hardware with Xcode. No one has verified it builds, launches, or passes App Review's basic functionality checks.

No signing, no notarization

Without a Developer Program account there is no Apple Distribution certificate, no Developer ID certificate, and no notarization — all required before Mac OS Gatekeeper or the App Store will accept a build.

What is real today

Native SwiftUI source code, reviewable now

The client is written as a native SwiftUI app wrapping the same local-first gateway the Windows and Android clients use, with StoreKit 2 for in-app tier purchases and biometric authentication for the approval register. It has not been built or tested on a device.

Component Status
SwiftUI app shell & WebKit bridge Source written, not yet compiled on real Apple hardware
StoreKit 2 in-app tier purchases Source written against the same 4 tiers as Windows/Android, not yet tested against a real sandbox
Biometric (Face ID / Touch ID) authentication Source written, not yet tested on a device
Compiled, signed, notarized installer Does not exist
App Store Connect listing Does not exist; no app record has been created

Available today

Windows and Android are real, signed releases

ThreadForge already ships on the Microsoft Store (signed by Microsoft) and Google Play. If you're on a Mac or iPhone today, the web workspace at the live demo runs the same suite in your browser.
